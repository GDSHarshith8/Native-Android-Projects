# Task Checker

**Task Checker** is a modern and intuitive mobile application designed to simplify your life by helping you manage your tasks effectively. With a clean, user-friendly interface and powerful features, it's the perfect tool to stay organized and productive—whether you're handling daily chores, work projects, or personal goals.

---

## ✨ Features

### Task Management

- **Add and Delete Tasks**  
  Effortlessly create new tasks with a simple text input. Delete tasks with a quick left swipe.

- **Mark as Done**  
  A right swipe on any task marks it as finished, providing a satisfying and efficient way to track your progress.

- **Update Task Status**  
  Tasks can be marked as finished or unfinished with a single swipe, helping you keep your list accurate.

---

### Filtering and Organization

- **Filter by Status**  
  Quickly view tasks by their status—All, Finished, or Unfinished. This helps you focus on what matters most and track your accomplishments.

- **Search Functionality**  
  A simple search bar allows you to find specific tasks in seconds, no matter how long your list is.

---

### Intuitive User Experience

- **Onboarding**  
  A beautiful and informative onboarding screen guides new users through the app's core features, ensuring they can start using the app immediately.

- **Simple Interface**  
  The app's design is minimal and clutter-free, allowing you to focus on your tasks without distractions.

- **Fluid Animations**  
  Smooth transitions and animations make interacting with the app feel responsive and enjoyable.

---

## 🛠️ Tech Stack

**Task Checker** is built entirely with **Jetpack Compose**, the modern Android UI toolkit.

- **Kotlin**  
  The core programming language for a concise and safe codebase.

- **Jetpack Compose**  
  For a declarative and performant UI.

- **Material 3**  
  To ensure a beautiful and consistent design with the latest Android standards.

- **Coroutines**  
  For handling asynchronous operations, such as database access, efficiently and without blocking the UI thread.

- **Hilt**  
  A dependency injection framework that reduces boilerplate and makes code more testable.

- **Preferences DataStore**  
  A modern and safe way to store key-value pairs, ideal for simple data like user settings or onboarding status.

- **Room Database** 
  A lightweight and robust database library for local data persistence.
